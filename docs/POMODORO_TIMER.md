# Pomodoro timer behavior

The timer stores UTC start and end timestamps with the workspace. The browser calibrates its clock from the server's HTTP `Date` header when it loads or saves a workspace, then computes the remaining time from those timestamps. Hidden tabs and suspended devices therefore catch up from the saved end time instead of counting background interval ticks. A focus run records its active intervals together, carries partial minutes across pauses and local midnight, and uses a stable run ID so recovering the same expired timer cannot add the same focus minutes twice.

A completed focus starts a five-minute short break, or a fifteen-minute long break after every fourth completed focus. A completed break starts a new focus session. Skipping a break starts focus immediately. Reopening a tab after an expired timer records the elapsed focus interval and returns to idle; it never starts a new focus session automatically. An unexpired timer keeps its saved owner. Ownership IDs live in `sessionStorage`, so each tab has separate control; the server's workspace revision check rejects concurrent changes, and the timer card shows when another tab or device owns the timer.

Timer sounds use the Web Audio API as a best-effort cue. Browsers can suspend or block playback when there has been no recent user gesture, and mute disables sound. A visible status message is shown at each timer transition even when playback is blocked. Native browser buttons keep the timer controls available to keyboard users.

The automated regression suite covers focus and break transitions, pause/resume and early finish, recovery after an expired timer, focus interval accounting across pauses and midnight, server/device clock offset, replay-safe totals, timer ownership conflicts, and visible completion feedback when browser audio is rejected. This repository does not include an automated mobile browser/device matrix; validate supported desktop and mobile browsers, light and dark themes, and keyboard-only operation against the exact release target before launch.
