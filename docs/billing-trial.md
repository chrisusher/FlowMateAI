# Pro trial and conversion

The trial uses the same Stripe Checkout subscription as a paid purchase. The customer chooses a configured monthly or annual price; a payment method is not required to start. Stripe creates one subscription with a 14-day trial. If a payment method is on file, the chosen price is charged when the trial ends unless cancelled first. A customer can add a payment method through the billing portal. Stripe cancels at trial end if no payment method is available.

Configure Stripe price IDs in `Stripe:Gbp:MonthlyPriceId`, `Stripe:Gbp:AnnualPriceId`, and equivalent `Stripe:Usd` and `Stripe:Eur` settings. The legacy `Stripe:MonthlyPriceId` and `Stripe:AnnualPriceId` are GBP fallbacks. The intended GBP launch prices are £4.99 monthly and £50 annually; create and verify corresponding Stripe prices before enabling checkout. USD and EUR amounts have not been selected and must be configured separately. The app only offers a currency/interval when Stripe confirms the configured price's currency and interval; configure all prices in the appropriate test or live account. Selecting a currency without a configured price shows pricing as unavailable.

The trial return page reports the confirmed end date when the webhook has arrived. Pro access is granted only from the server-side Stripe entitlement. If the webhook is delayed, the page reports that confirmation is pending. When a trial expires or is cancelled, the existing workspace remains stored and uses Free plan limits.

The server records trial use from subscription webhooks and reconciles it with Stripe subscription history before another trial can be created. Repeated trial requests for the same customer reuse the existing trial Checkout session, including its original price, even if the customer changes the monthly/annual selection. Paid Checkout requests reuse a session only for the same price. A conflicting open subscription checkout blocks a new checkout: return to its original selection to finish it, or wait for it to expire. All subscription requests share a Stripe idempotency key across prices and checkout types to prevent simultaneous requests from creating separate subscriptions.

The server saves the confirmed subscription's renewal interval from Stripe and includes it in the billing summary. Trial renewal wording uses that interval independently of the pricing toggle, including after a fresh page load. If the interval is not yet known, the wording refers to the subscription charge without guessing its cadence.
